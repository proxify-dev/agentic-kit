[tracer] That read the tool-call trace store directly. The shell already reads it: `tracer trace` (every tool call from every session, newest first — filter by --tool/--server/--session/--outcome/--since) · `tracer trace get <tool_use_id>` (one call whole: its input and output) · `tracer trace stats` (totals).
