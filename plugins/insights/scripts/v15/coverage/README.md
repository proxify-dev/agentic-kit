## Where the playbook teaches the opposite of the substrate

- **context:write-down-what-it-cannot-know** — L3 is well covered for the basic move (a line in a file every session loads). Not taught anywhere: the test for what earns a line, fixing the misleading code instead of writing a rule (only named as hands-on track challenge 7), and the tight rules that must govern an agent-written file. Worse, self-improving-loop and prompting-craft say only 'tell Claude to update CLAUDE.md', with no limit on what goes in, which is the unsupervised version the L3 text rules out. Nothing at all teaches L4.
- **context:keep-always-loaded-small** — L2 (cut when it bites, stay under about 200 lines) is taught. L3 is not: nothing shows how to trim, merge overlapping rules, settle contradictions, reword a 'don't' into what to do, retire a rule once its cause is fixed, or diagnose an ignored rule (too long, ambiguous, contradicted, misleading code). The compounding table in system-evolution only ever adds rules (week 1: 3 rules, week 2: 2 more, and so on), which teaches instruction stacking. self-improving-loop also says 'Instructions that get violated repeatedly need hooks, not CLAUDE.md entries', which is the opposite of the level-guide ruling that an ignored rule is a context problem. No page teaches L4 (a size/duplicate/contradiction check the agent can't skip).
- **prompt:reword-the-ask** — L2 is partly covered (do not repeat louder, give the missing context, be specific not emphatic, smaller steps) but no page shows the full move: stop it, name the defect and what it was not told, give the reason, say what to do instead, vary the example. Nothing teaches varied examples; permutation-frameworks teaches the opposite use (one canonical reference). Nothing on Esc/refuse-with-reason, rewind, or 'say what to do instead'. L3 and L4 have nothing that teaches them, and the pages that touch kept prompts teach the opposite (append a rule after every correction: prompting-craft 'CLAUDE.md as a Self-Updating Artifact', self-improving-loop 'CLAUDE.md as a Living Document', system-evolution 'Trace, Patch, Never Repeat'; robots-first 'What NOT to do' and self-improving-loop 'add them as explicit Don't do X rules' contradict Pink Elephant; setup/claude-md's own example uses 'NEVER commit .env files', contradicting the no-shouting advice). Drafter's learn links /reference/common-pitfalls and /patterns/prompting-craft exist and say what the draft claims for L2.
- **orchestration:fresh-run-per-task** — Weakest-covered practice. Only the by-hand handoff file and a single overnight tip exist. The Ralph loop is one vocabulary row. No page shows a list, a saved prompt, a loop command, headless runs, limits per item, or resuming after a crash. Permutation Frameworks fans out N items in ONE prompt/session, which is the opposite of a fresh run per task (do not credit it).
